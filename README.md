✈️ Smart Booking Platform for Travel & Tourism Agencies
An interactive web platform designed specifically for travel agencies to streamline trip bookings, calculate costs instantly, and centralize communication channels—featuring direct integration with WhatsApp.

🚀 Key Features
Instant Booking Calculator: Select the destination, mode of travel (land/air), and number of passengers to accurately calculate costs in both Dinars and Dollars.

WhatsApp Automation: Send a complete, organized booking summary directly to the company’s number with a single click—no need for the customer to type a message.

Integrated Links Page (Link-in-Bio): Consolidates social media accounts (WhatsApp, Instagram, Facebook) and location maps into one elegant interface.

Data Validation: Checks user inputs and verifies the accuracy of phone numbers and essential fields before finalizing the request.

🛠️ Technologies Used
HTML5 – For structuring the user interface.

CSS3 – For modern design and attractive styling.

JavaScript (Vanilla) – For calculation logic, validation, and WhatsApp message encoding (encodeURIComponent).
